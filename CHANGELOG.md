# Changelog

## 0.0.1

- Deterministic schema-v1 graph records, stable identities, exact source/derived provenance and strict JSON round-trip validation.
- Pinned local Git tree ingestion, configurable path filters, JSON rules and CODEOWNERS mapping.
- Typed library and CLI for neighbors, reverse neighbors, affected closure and shortest causal paths.
- CI coverage gate and smoke verification of the installed npm tarball.

Release notes must list public API/CLI changes, schema changes, compatibility requirements, known limitations and the validation performed. Schema version and package version are separate: unsupported schema versions fail explicitly. Pre-1.0 API changes must be called out in the release notes. No automatic schema migration is available in 0.0.1.
