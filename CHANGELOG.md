# Changelog

## 0.0.1

RepoGraph's first internal/pre-public slice provides:

- deterministic typed graph records with stable node/edge identities;
- exact provenance and deterministic JSON serialization;
- pinned Git tree ingestion with path filters and CODEOWNERS-like generic path rules;
- forward/reverse neighbors, reverse affected closure and causal path explanation;
- TypeScript library exports plus a deterministic JSON CLI;
- CI typecheck, tests, coverage threshold, build and CLI smoke checks.

This is intentionally a pre-1.0 contract. The first public release target remains **1.0.0**.
